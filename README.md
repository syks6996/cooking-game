Sizzle & Serve — run the Ember & Thyme Diner kitchen in a 3-minute lunch shift: take ingredients from the pantry, chop them on the board, cook patties and pasta on the stove, build each dish on the plating counter and serve it at the window before the ticket runs out. Five recipes combine in different ways, orders arrive faster as the shift goes on, and the last 30 seconds are rush hour. A complete original cooking game in plain HTML5 canvas and JavaScript, no libraries, no network, with keyboard and mouse controls and synthesized sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
